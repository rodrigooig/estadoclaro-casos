# Reguladores y regulados

Integrantes de organismos que regulan, fiscalizan o resuelven disputas de un sector, con
intereses declarados en empresas de ese mismo sector. El hallazgo no requiere una venta al
propio organismo: el nexo es el ámbito que la persona regula.
